# DLP Add-in

The DLP Add-in for Outlook scans an email's subject and body, along with supported file attachments, for potential personally identifiable and protected health information before sending. Select **Scan Email** in the Outlook task pane to review detected categories, examples, recommended actions, and an overall risk score.

Supported attachments include common text files and PDF, Word, Excel, and PowerPoint formats.

Detection is pattern-based using regular expressions and may not identify every instance of sensitive information. Review the message and attachments before sending.
